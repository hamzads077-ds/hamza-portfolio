# Muhammad Hamza Shah — Portfolio

This dependency-free static portfolio presents Muhammad Hamza Shah as a BS Statistical Data Science student and aspiring data scientist focused on Python, SQL, statistics, data analysis, relational databases, Git, and GitHub. It includes selected practice and GitHub Skills learning projects, a print-ready ATS resume, and direct contact links. The live site is [hamzads077-ds.github.io/hamza-portfolio](https://hamzads077-ds.github.io/hamza-portfolio/).

Key files are `index.html`, `styles.css`, `script.js`, and the downloadable `resume.html`; the HTML resume is a plain ATS-friendly document that downloads directly from the homepage. Run locally with `python -m http.server 8000`. GitHub Pages is enabled for `main` from the repository root and automatically redeploys after pushes.
