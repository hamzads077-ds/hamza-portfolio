# Muhammad Hamza Shah — Portfolio

This dependency-free static portfolio presents Muhammad Hamza Shah as a BS Statistical Data Science student and aspiring data scientist, with a focus on Python, SQL, statistics, data analysis, relational databases, Git, and GitHub. It includes a responsive profile site, selected learning projects, an ATS-friendly text-first resume, and direct contact links; the live site is [hamzads077-ds.github.io/hamza-portfolio-site](https://hamzads077-ds.github.io/hamza-portfolio-site/).

## Key contents

- `index.html` — responsive portfolio with about, learning focus, selected projects, education, and contact sections
- `resume.html` — ATS-friendly resume with Summary, Education, Technical Skills, Professional Development, Projects, and Links / Contact
- `styles.css` and `script.js` — presentation and mobile navigation
- Public projects: SQL Student Data Analysis, Python Practice Projects, and Mario Database
- Learning references: GitHub Skills and [freeCodeCamp SQL/database coursework](https://www.freecodecamp.org/)

## Deployment

Run locally with `python -m http.server 8000`, then open `http://localhost:8000`. GitHub Pages is enabled for `main` from the repository root; after pushing changes, GitHub automatically redeploys the site at the live URL above. Open `resume.html` and use **Print → Save as PDF** when a PDF copy is needed.
